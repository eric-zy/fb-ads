# 前端生产静态产物部署

生产服务器只接收编译后的 `frontend/dist/`，不安装 Node，也不执行前端构建。

构建机执行：

```bash
cd frontend
npm ci
npm run build
cd ..
npm run build
```

服务器上传并解压后执行：

```bash
test -f frontend/dist/index.html
docker compose -f deploy/docker-compose.yml -f deploy/docker-compose.frontend-dist.yml build nginx
docker compose -f deploy/docker-compose.yml -f deploy/docker-compose.frontend-dist.yml up -d --force-recreate nginx
```

API、Worker、Beat 不受影响。`frontend-dist/` 不提交 Git，只通过发布包传输。
