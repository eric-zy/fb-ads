# 工作日志：FB 海外 Connector 拆分

日期：2026-09-16  
分支：`fb-connector-overseas`

## 一、今日目标

将 FB/Meta 业务从国内 SaaS 主系统中拆分出来：

- 国内服务器运行 SaaS、租户、权限和业务数据。
- 海外服务器运行 FB Connector，负责访问 Meta API 和保存 FB 凭证。
- 国内 SaaS 通过签名 HTTPS 请求调用海外 Connector。

## 二、已完成工作

### 1. 配置与安全边界

- 增加 `APP_ROLE`、`FB_ACCESS_MODE`、`FB_CONNECTOR_ENABLED` 等运行配置。
- 增加国内 SaaS 与海外 Connector 的签名通信配置。
- 国内 SaaS 在 Connector 模式下不保存 FB Access Token。
- 增加 HMAC 请求签名和 Bearer 服务令牌校验。
- 增加配置占位符检查，防止生产环境使用示例值启动。

### 2. 海外 Connector 服务

- 新增独立 `fb_connector` FastAPI 服务。
- 新增独立 PostgreSQL、Redis、Celery Worker、Celery Beat 配置。
- 新增海外凭证加密存储。
- 新增 OAuth、SDK Login、Business、广告账户、Page、报表等接口。
- 新增独立 Connector Alembic 迁移链。

### 3. OAuth 链路

- 国内 SaaS 的 SDK Login 在 Connector 模式下转发到海外。
- OAuth 授权地址由 Connector 生成。
- Meta 回调地址使用海外地址：

```text
https://iornix.com/internal/meta/oauth/callback
```

- 国内 `/businesses`、`/ad-accounts`、`/complete` 已支持海外凭证 ID。
- 国内最终只保存 `connector_credential_id`，不保存海外 Access Token。

### 4. 广告和报表链路

- Campaign 查询切换到海外 Connector。
- AdSet 查询切换到海外 Connector。
- Ad 查询切换到海外 Connector。
- Campaign 暂停、AdSet/Ad 启停切换到海外 Connector。
- 报表查询支持 Connector 模式和精确日期范围。

### 5. 投放创建链路

- 设计并新增 Connector 投放协议文档。
- 协议覆盖：
  - Campaign
  - AdSet
  - Creative
  - Ad
- 新增 `connector_campaign_builder.py`，只生成 payload，不访问 Meta、不读取 Token。
- 新增完整异步部署接口 `/internal/meta/campaigns/deploy`。
- 海外按 Campaign → AdSet → Creative → Ad 顺序创建。
- 国内增加海外任务状态轮询。
- 成功后回写 Campaign、AdSet、Ad 对象 ID。

### 6. 异常补偿

- 新增海外 `/internal/meta/campaigns/cleanup` 接口。
- 投放创建失败时按 Ad → Creative → AdSet → Campaign 逆序清理。
- 补偿失败会记录对象 ID和错误信息。
- 国内轮询任务会调用 `_finalize_job_if_done()` 汇总总 Job 状态。
- 支持 `SUCCESS`、`FAILED`、`PARTIAL_SUCCESS`。

### 7. 部署验证

海外服务器已完成：

- Docker 镜像构建成功。
- PostgreSQL 健康。
- Redis 健康。
- Connector API 启动成功。
- Celery Worker 启动成功。
- 8100 端口监听正常。

首次健康检查因服务刚启动过早出现连接重置，随后日志确认 API 已完成启动。

## 三、Meta 开发者后台配置

需要配置：

- App ID、App Secret。
- App Domains：`iornix.com`。
- Valid OAuth Redirect URI：

```text
https://iornix.com/internal/meta/oauth/callback
```

- Facebook Login。
- Marketing API。
- 申请 `business_management`、`ads_management`、`ads_read` 等权限。
- 配置隐私政策、数据删除和服务条款页面。
- 验证 `iornix.com` 域名。

## 四、当前配置要点

国内 SaaS：

```env
APP_ROLE=saas
FB_ACCESS_MODE=connector
FB_CONNECTOR_ENABLED=true
FB_CONNECTOR_BASE_URL=https://iornix.com
```

海外 Connector：

```env
APP_ROLE=fb_connector
FB_ACCESS_MODE=direct
FB_CONNECTOR_ENABLED=true
FB_OAUTH_REDIRECT_URI=https://iornix.com/internal/meta/oauth/callback
```

两端必须一致：

- `FB_CONNECTOR_SIGNING_KEY`
- `SAAS_INTERNAL_SIGNING_KEY`
- `CONNECTOR_SERVICE_TOKEN`

## 五、发现的问题和风险

### 已处理

- 部署脚本占位符导致无法启动。
- Windows 换行符导致 Linux 执行脚本报错。
- 海外 API 启动阶段健康检查过早。
- 海外任务 Creative/Ad 嵌套参数处理问题。
- 海外素材任务临时文件清理缺少 `os` 导入。
- 国内轮询重复回写映射问题。

### 尚未完全处理

- 素材上传暂未迁移，仍依赖国内本地文件路径。
- 投放创建真实 Meta 账号联调尚未完成。
- pytest 因本地虚拟环境缺少 `fastapi` 依赖未能完整执行。
- 海外 Celery 当前以 root 用户运行，仅有安全警告，未影响启动。
- 需确认所有配置项在服务器中均为独立行，不能将多个变量写在同一行。
- 之前聊天中曾出现敏感配置值，相关 App Secret、签名密钥、服务令牌、数据库密码和 Redis 密码应全部轮换。

## 六、当前链路状态
